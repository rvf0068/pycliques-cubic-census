# Certificate bundles

## Order-14 behavior

- **coaffine_order14_stage0.json**: 396 expansive stable-image witnesses for every recorded depth-zero divergence.
- **coaffine_order14_stage1.json**: 72 expansive stable-image witnesses for every recorded depth-one divergence.
- **coaffine_order14_stage2.json**: 22 witnesses from the first production-package rediscovery.
- **coaffine_order14_stage2_followup.json**: the final 11 stage-two witnesses.
- **308.json**: the recovered 22-cut incidence certificate and retraction for graph 308.

Together these establish all **502 divergent** order-14 cases. The 18 clique-null cases are independently checked by their exact paring-to-a-point records in the behavior ledger. Thus all 520 determined behavior cases have replayable proofs; the remaining 20 cases are unresolved.

The stage-zero and stage-one bundles were regenerated by finite-domain coaffine searches with arc consistency and an expansive-leaf acceptance test. The stage-two bundle combines the first production-package rediscovery with deeper native and implicit-incidence follow-ups. The eleven last recoveries are:

| Route | Graph IDs |
|---|---|
| Native octahedral coaffine search | 100, 189, 241, 419, 430, 432 |
| Native general coaffine search with expansive stable image | 450 |
| Implicit incidence-cut hybrid, retraction onto an octahedron | 135, 150, 253, 437 |

The four old historical-only records (150, 252, 270, 472) now all have fresh certificates. The source labels in the CSV are preserved for provenance, not as current evidence status.

## Independent replay

The saved maps are checked without rerunning any search:

```sh
uv run --with networkx python scripts/validate_census.py
uv run --with networkx python scripts/verify_coaffine.py --report coaffine-replay.json
```

The first command verifies the original datasets, the 18 point reductions, and graph 308's 22-cut retraction. The second reconstructs every host from graph6 and verifies all 501 coaffine maps, their weak-morphism and coaffinity conditions, stable-image retractions, and invariant expansive factors. For certificates marked `target_type: octahedral`, it additionally checks that the stable image is an induced O_d and that f^2 is a retraction onto it. The combined replay therefore checks all 502 divergence proofs and all 18 null proofs.

## Stage-two discovery provenance

All runs used the pinned monorepo commit `e1e9ed04f5c1f962a5f7e70312fb8df16e5a6a78`.

- [Initial bounded portfolio](../research/stage2-discovery-20261126.json): 22 of the 33 stage-two coaffine cases.
- [Deeper native portfolio](../research/stage2-discovery-deep-20261127.json): 7 of the 11 initially outstanding cases.
- [Implicit incidence-cut portfolio](../research/stage2-incidence-20261127.json): 9 of those 11 cases, including independent alternative witnesses for 100, 189, 241, 430 and 432.

The deep native run used 15-second native calls, 30-second SAT calls and a one-million-state cap. Its first SAT invocation was misconfigured with the unsupported `value_order='fiber'` option and did not solve; the checked script now omits that option and the workflow installs `libz3-4`. This does not affect any saved proof: all four cases missed by the deep native portfolio were recovered by the incidence run.

The incidence portfolio constructs P2 as the paring core of the implicit clique graph of P1. It uses the hybrid walk/SAT backend with 60 seconds per seed, 250,000 walk steps, one million SAT states, and seeds 139, 137, 271. Every positive result was independently checked at discovery time as an induced octahedron, an ordinary retraction, a coaffine endomorphism and an expansive stable-image witness. The saved coaffine map is sufficient for the lightweight repository verifier; the run report retains the incidence-search metadata.

The two discovery scripts and workflows are included for future reproduction:

- `scripts/discover_stage2_deep.py` / `.github/workflows/discover-stage2-deep.yml`
- `scripts/discover_stage2_incidence.py` / `.github/workflows/discover-stage2-incidence.yml`

The workflows are manually dispatchable. Timeouts or missing witnesses in an individual search are inconclusive; saved positive maps are replayed exactly by the fast CI.

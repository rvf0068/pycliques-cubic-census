# Certificate bundles

- **coaffine_order14_stage0.json**: 396 fresh finite coaffine maps, for every recorded depth-zero divergence.
- **coaffine_order14_stage1.json**: 72 fresh finite coaffine maps, for every recorded depth-one divergence.
- **coaffine_order14_stage2.json**: 22 fresh witnesses obtained with the pinned monorepo, including three formerly historical-only verdicts.
- **308.json**: the recovered depth-two cut and retraction witness, independently replayed by the existing validator.

The stage-zero and stage-one coaffine bundles were regenerated by a finite-domain search with weak-edge constraints, arc consistency, and an expansive-leaf acceptance test. The stage-two bundle was generated by the production native coaffine and octahedral solvers and the production SAT solver, using [this discovery script](../scripts/discover_stage2.py). They are newly constructed witnesses, **not recovered copies of the original unavailable archive**. Their targets need not coincide with the historical target descriptions. Historical source and target columns are unchanged.

For each ID, the stage is relative to the deterministic pared sequence: complement the cubic input, fold the least removable vertex (choosing the least dominator), relabel survivors in increasing old-label order, and repeat after constructing the clique graph with maximal completes sorted lexicographically by increasing vertex tuples. Map entries are images of consecutive host vertices. Factors are lists of host vertices. The verifier checks the full morphism, coaffinity, stable image, its explicit power retraction, and nonempty pairwise completely joined invariant factors (at least three, or two with one connected).

The mathematical justification is the expansive summand criteria and admissible inclusion for coaffined graphs, in Larrión, Neumann-Lara and Pizaña, *On expansive graphs*, European Journal of Combinatorics 30 (2009), 372–379, Theorems 2.4, 3.6 and 4.6. See the survey for the argument via stable images and retractions. A coaffine endomorphism alone is not a divergence certificate.

Replay (NetworkX only, no searches):

```sh
uv run --with networkx python scripts/validate_census.py
uv run --with networkx python scripts/verify_coaffine.py --report coaffine-replay.json
```

Together these commands replay 491 divergent and 18 clique-null cases, a total of 509 behavior certificates. Eleven further recorded divergence verdicts are not yet replayable from this repository; this includes the one remaining historical-only case (150). Twenty cases remain unresolved in the research ledger. No topology witness is established merely by comparing the imported homotopy records.

## Stage-two discovery

The pinned monorepo commit is `e1e9ed04f5c1f962a5f7e70312fb8df16e5a6a78`.
[Discovery run 45936473197](https://github.com/rvf0068/pycliques-cubic-census/actions/runs/45936473197)
attempted all 33 outstanding recorded divergent cases. Native calls used a five-second
limit each (200,000 states); SAT calls used ten seconds (1,000,000 conflicts,
6,000,000 clauses, 3072 MiB). Of the 22 witnesses, 15 were found by the
general native coaffine search, three by reordered native octahedral search,
and four by SAT octahedral search. The 11 other outcomes are inconclusive,
not negative mathematical results.

To repeat a bounded attempt, install the pinned monorepo's pycliques package
and build its native backend; use the same Python environment for the script:

```sh
python -m pycliques.octahedral_coaffine_native --build
python scripts/discover_stage2.py --seconds 5 47 419 379
```

The complete [discovery record](../research/stage2-discovery-20261126.json)
gives the outcome and job ID for every attempted case. The ordinary CI
replays the certificates without rediscovery or pycliques.

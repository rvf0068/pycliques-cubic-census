* Scope and evidence

This workbook accompanies =cubic_complements_survey.tex=. It is an executable research guide, not a claim that the entire census has been rerun using today's packages. It contains the recovered order-14 ledger for *every one of the 540 inputs*, including the recorded wedge decompositions of both \(\Delta(G)\) and \(\Delta(K(G))\), the behavior, depth and historical certificate method. The table below is embedded; no external CSV is needed for these expectations.

Of the 540, 509 are complements of connected cubic graphs and 31 are complements of disconnected cubic graphs. There are 502 recorded divergent, 18 clique-null, 20 unresolved. Four divergent verdicts (150, 252, 270, 472) were carried forward from older reports, but their maps have not been recovered in the reconstructed ledger. Treat them as *historical only* until a new witness is found or the old certificate is recovered. The other 498 were recorded with replayed positive witnesses. This workbook does not turn archived claims into fresh production-package results merely by reading the ledger.

All 540 first-level homotopy pairs were reported as exact wedges (19 equal, 521 different). A dictionary of dimension:multiplicity denotes a wedge; the empty dictionary denotes a point. Neither Betti-number equality nor a timeout is an exact homotopy certificate. Some hard topology cases were resolved with archived research prototypes, and several stage-two behavior proofs used specialized local search heuristics not yet fully integrated into the public APIs. The package-only route below provides a principled fresh search and verifies positive results; it is not a guarantee of success at the specified budgets. Every row gets its own route, expected result and output status. In particular there is no assertion that =find_coaffine_endomorphism= alone certifies divergence.

The source reviewed for this workbook is the current default branch of [[https://github.com/rvf0068/pycliques-project][pycliques-project]], including search results pinned to commit =e1e9ed04f5c1f962a5f7e70312fb8df16e5a6a78=. Files examined include [[https://github.com/rvf0068/pycliques-project/blob/main/docs/general_retraction_and_implicit_cliques.md][general retraction and implicit cliques]], [[https://github.com/rvf0068/pycliques-project/blob/main/docs/clique_behavior.md][clique behavior]], =coaffine_endomorphisms.py=, =octahedral_incidence.py=, =clique_sequence.py=, and =homotopy_type.py=. The packages were not installed in the survey runtime, so the full package run must be performed in your own monorepo environment. I did independently replay the cut certificate of 308 with NetworkX, and check the census transcription and the standalone verification routines as described below. No PR or change to the monorepo is made.

References: Rafael Villarroel-Flores, [[https://doi.org/10.1016/j.disc.2022.113230][On the clique behavior and Hellyness of the complements of regular graphs]], Discrete Mathematics 346 (2023), 113230; the LAGOS 2023 draft /The Clique Behavior of the Complement of Cubic Graphs/; Larrión, Neumann-Lara and Pizaña, [[https://doi.org/10.1016/j.ejc.2008.05.005][On expansive graphs]], EJC 30 (2009), 372--379, Theorems 2.4, 3.6 and 4.6; Frías-Armenta, Neumann-Lara and Pizaña, /Dismantlings and iterated clique graphs/, DM 282 (2004), 263--265. The data are from [[https://houseofgraphs.org/Cubic][House of Graphs]].

** Stable images of coaffine endomorphisms

A coaffine weak morphism \(f\) sends every vertex outside its closed neighborhood. If the image stabilizes at \(R\), some power of \(f\) is a retraction onto \(R\); \(f|_R\) is an automorphism. The expansive criterion checks an invariant subjoin with either three nonempty factors or two factors with one connected. Equivariance is essential; the fact that an induced graph is divergent is not sufficient. The following adapter uses the package verifier and NetworkX to check the mathematical acceptance predicate used in the historical stage-zero and stage-one research screen. It also recognizes invariant subjoins of a stable image, not only those coming from components of its entire complement. It does not replace the package CSP engine.

#+begin_src jupyter-python
def stable_image(G, f):
    assert pc.verify_coaffine_endomorphism(G, f)
    R = set(G)
    m = 0
    while (S := {f[v] for v in R}) != R:
        R, m = S, m+1
    # Permutation orbits of the stable image.
    todo = set(R)
    orbits = []
    while todo:
        v = min(todo)
        orbit = {v}
        w = f[v]
        while w != v:
            orbit.add(w)
            w = f[w]
        orbits.append(orbit)
        todo -= orbit
    return R, m, orbits

def expansive_subjoin(G, f):
    R, m, orbits = stable_image(G, f)
    J = nx.Graph()
    J.add_nodes_from(range(len(orbits)))
    for i, j in it.combinations(J, 2):
        if all(G.has_edge(u,v) for u in orbits[i] for v in orbits[j]):
            J.add_edge(i,j)
    # Three disjoint nonempty invariant summands.
    for i,j in J.edges:
        common = set(J[i]) & set(J[j])
        if common:
            return [orbits[i], orbits[j], orbits[min(common)]]
    # One invariant connected component of the union of orbits joined to A.
    for i in J:
        B = set().union(*(orbits[j] for j in J[i]))
        for component in nx.connected_components(G.subgraph(B)):
            if {f[v] for v in component} == component:
                return [orbits[i], set(component)]
    return None

def verify_expansive(G, f):
    if not pc.verify_coaffine_endomorphism(G, f):
        return None
    factors = expansive_subjoin(G, f)
    if factors is None:
        return None
    R,m,orbits = stable_image(G,f)
    # Idempotent power: at least m, divisible by the cycle lengths.
    order = math.lcm(*(len(o) for o in orbits))
    exponent = max(1, (m+order-1)//order)*order
    projection = {v:v for v in G}
    power = dict(f)
    k = exponent
    while k:
        if k & 1:
            projection = {v:power[w] for v,w in projection.items()}
        power = {v:power[w] for v,w in power.items()}
        k >>= 1
    target = G.subgraph(R).copy()
    assert pc.verify_retraction_witness(G, target,
              (projection, {v:v for v in target}))
    assert all({f[v] for v in A} == A for A in factors)
    assert all(G.has_edge(a,b) for A,B in it.combinations(factors,2)
               for a in A for b in B)
    assert len(factors) >= 3 or any(nx.is_connected(G.subgraph(A)) for A in factors)
    return dict(map=f, stable_image=sorted(R), exponent=exponent,
                projection=projection, factors=[sorted(A) for A in factors])

** Octahedral maps, incidence retractions and special octahedra

For \(O_d=\overline{dK_2}\), \(K(O_d)\cong O_{2^{d-1}}\). A retraction onto \(O_d\), \(d\ge3\), proves divergence, and any special octahedron is such a retract. If a special witness has a maximal host transversal \(a_i\), send each external vertex to the mate \(b_i\) of a nonadjacent \(a_i\). The retraction verifier checks this map. For ordinary octahedral searches the result object includes the inclusion and projection; independently verify both rather than trusting the solver status. Stage-two SAT and native results use different heuristics; discovery budgets are not mathematical hypotheses.

def check_octahedral_result(host, ans):

        return None
    assert ans.dimension >= 3
    assert ans.retraction is not None and ans.inclusion is not None
    assert pc.verify_induced_octahedron(host, ans.antipodal_pairs)
    target = host.subgraph(ans.inclusion.values()).copy()
    assert pc.verify_retraction_witness(host,target,(ans.retraction,ans.inclusion))
    assert pc.verify_coaffine_endomorphism(host,ans.endomorphism)
    assert all(ans.endomorphism[ans.endomorphism[v]] == ans.retraction[v] for v in host)
    return dict(dimension=ans.dimension, pairs=ans.antipodal_pairs,
                projection=ans.retraction, inclusion=ans.inclusion,
                coaffine=ans.endomorphism)

def special_retraction(H):
    w = pc.find_special_octahedron_witness(H)
    if w is None:
        return None
    assert pc.verify_special_octahedron_witness(H,w)
    pairs = tuple(zip(w.clique,w.antipodes))
    V = {v for pair in pairs for v in pair}
    r = {v:v for v in V}
    for v in set(H)-V:
        r[v] = next(b for a,b in pairs if v != a and not H.has_edge(v,a))
    assert pc.verify_induced_octahedron(H,pairs)
    assert pc.verify_retraction_witness(H,H.subgraph(V),(r,{v:v for v in V}))
    return dict(pairs=pairs,projection=r,dimension=len(pairs))

            return {**base,'actual':'CONVERGENT','route':'point paring',
                    'orders':[len(seq[j]) for j in range(row['stage']+1)]}
        return {**base,'actual':'NOT_REPRODUCED','route':'point paring'}
    stage = row['stage'] if row['stage'] is not None else 2
    H = seq[stage]
    if H is None:
        return {**base,'actual':'HOST_LIMIT'}
    if stage < 2 or row['behavior_source']=='second_screen':
        proof = expansive_search(H,states=states,seconds=seconds,exhaustive_leaf=deep)
        if proof:
            return {**base,'actual':'DIVERGENT','route':'expansive stable image','proof':proof}
    if stage < 2:
        proof = special_retraction(H)
        if proof:
            return {**base,'actual':'DIVERGENT','route':'special O_d retraction','proof':proof}
    if stage == 2:
        source = row['behavior_source']
        backends = ['sat','auto'] if source=='sat_antipodal_csp' else ['auto','sat']
        for backend in backends:
            try:
                proof,status = oct_search(H,backend=backend,states=states,seconds=seconds)
            except (RuntimeError,ValueError) as err:
                status = f'BACKEND_UNAVAILABLE: {err}'
                proof = None
            if proof:
                return {**base,'actual':'DIVERGENT','route':f'octahedral {backend}','proof':proof}
        if deep:
            for seed in (137,139,71):
                # A deterministic random relabel may produce a different
                # search tree. Transport the witness back to the host.
                nodes = list(H)
                rng = random.Random(seed); rng.shuffle(nodes)
                iso = {v:j for j,v in enumerate(nodes)}
                J = nx.Graph()
                J.add_nodes_from(range(len(H)))
                J.add_edges_from((iso[u], iso[v]) for u,v in H.edges)
                proof = expansive_search(J,states=states,seconds=seconds,
                                         exhaustive_leaf=True)
                if proof:
                    inv = {j:v for v,j in iso.items()}
                    f = {inv[u]:inv[v] for u,v in proof['map'].items()}
                    return {**base,'actual':'DIVERGENT','route':'relabel expansive',
                            'proof':verify_expansive(H,f)}
            for backend in ('walk','hybrid','sat'):
                try:
                    proof,status = incidence_search(seq,backend=backend,seconds=seconds,states=states)
                except (RuntimeError,ValueError) as err:
                    status = f'BACKEND_UNAVAILABLE: {err}'; proof=None
                if proof:
                    return {**base,'actual':'DIVERGENT','route':f'incidence {backend}',
                            'proof':proof}
    if standard:
        # Small cap by design; the explicit P2 routes above are separate.
        ans = pc.classify_clique_behavior(G,tries=min(stage+1,3),bound=300,
                                         clockwork_depth=0,retraction_depth=1)
        if ans.verdict.name != 'INDETERMINATE':
            return {**base,'actual':ans.verdict.name,'route':'package classifier',
                    'reason':ans.reason,'rule':getattr(ans.certificate,'rule',None)}
    return {**base,'actual':'NOT_REPRODUCED','route':'bounded portfolio'}

def exact_wedge(H, expected, *, max_simplices=1_000_000,
                seeds=(0,1,2), recursive_betti_states=4096):
    trials=[]
    for seed in seeds:
        h=pt.homotopy_type_with_verdict(H,max_simplices=max_simplices,
                    dong_seed=seed,recursive_betti_states=recursive_betti_states)
        wedge=getattr(h,'wedge',None)
        spheres=dict(wedge.spheres) if wedge is not None else None
        row=dict(seed=seed,exact=h.is_exact,verdict=h.verdict,
                 reason=h.reason,spheres=spheres)
        trials.append(row)
        if h.is_exact:
            return dict(status='VERIFIED' if spheres==expected else 'EXACT_MISMATCH',
                        expected=expected,actual=spheres,trials=trials)
    return dict(status='NOT_REPRODUCED',expected=expected,trials=trials)

def homotopy_one(identifier, *, max_simplices=1_000_000,
                 seeds=(0,1,2), recursive_betti_states=4096):
    row=LEDGER[identifier]
    seq=sequence(G14[identifier])
    result=dict(id=identifier,source=row['homotopy_source'])
    # P0 and P1 are homotopy equivalent to the actual G and K(G).
    for stage,key in enumerate(('G','KG')):
        H=seq[stage]
        if H is None:
            result[key]=dict(status='HOST_LIMIT',expected=row[key])
        else:
            result[key]=exact_wedge(H,row[key],max_simplices=max_simplices,
                    seeds=seeds,recursive_betti_states=recursive_betti_states)
    return result

def small_order(n, *, bound=500, tries=4, deep=False):
    results=[]
    for i,c in catalog(n).items():
        G=nx.complement(c)
        ans=pc.classify_clique_behavior(G,bound=bound,tries=tries,
                    clockwork_depth=0,retraction_depth=2)
        r=dict(order=n,id=i,cubic_graph6=nx.to_graph6_bytes(c,header=False).decode().strip(),
               status=ans.verdict.name,reason=ans.reason)
        if ans.verdict.name=='INDETERMINATE' and deep:
            seq=sequence(G)
            for j in range(3):
                H=seq[j]
                if H is None: break
                if len(H)==1:
                    r.update(status='CONVERGENT',reason='point paring',stage=j);break
                proof=expansive_search(H,exhaustive_leaf=True)
                if proof:
                    r.update(status='DIVERGENT',reason='expansive stable image',stage=j,proof=proof);break
                proof,status=oct_search(H,backend='auto')
                if proof:
                    r.update(status='DIVERGENT',reason='octahedral retract',stage=j,proof=proof);break
        # Explicit package result, with no assumed topology when not exact.
        seq=sequence(G)
        for j,key in enumerate(('G','KG')):
            H=seq[j]
            if H is not None:
                h=pt.homotopy_type_with_verdict(H,max_simplices=1_000_000)
                r[key]=dict(exact=h.is_exact,verdict=h.verdict,reason=h.reason)
        append_jsonl(f'order{n}_replay.jsonl',r)
        print(n,i,r['status'],flush=True)
        results.append(r)
    print(Counter(r['status'] for r in results))
    return results
